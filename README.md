# Whisgel González — Portfolio

Personal portfolio built with React, TypeScript, Vite, and Tailwind CSS. Bilingual (ES/EN), dark mode, and a curated selection of real projects.

## Stack

- React 19 + TypeScript
- Vite + Tailwind CSS v4
- react-i18next (ES/EN)
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deployed automatically to GitHub Pages on every push to `main` via GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).
